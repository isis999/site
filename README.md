# Florescer Fisioterapia — site institucional

Site responsivo em HTML, CSS e JavaScript, pronto para personalizar e publicar com GitHub Pages.

## Arquivos
- `index.html`: conteúdo e estrutura das páginas/seções.
- `style.css`: identidade visual, layout responsivo e estilos.
- `script.js`: menu mobile, ano automático e configuração do botão de WhatsApp.
- `assets/`: imagens usadas no site.

## Antes de publicar
1. Abra `script.js` e preencha `whatsapp` com o número oficial, incluindo código do país e DDD, somente números (ex.: `5511999999999`).
2. No `index.html`, substitua “Adicione aqui o endereço da clínica” pelo endereço real.
3. Confira os serviços descritos e ajuste para corresponder exatamente aos serviços oferecidos pela clínica.
4. Confira se a imagem `assets/logo-referencia.png` é a versão correta da logo. Se necessário, substitua-a por uma imagem oficial da marca mantendo o mesmo nome do arquivo.
5. Se quiser, troque as imagens na pasta `assets/` por fotografias reais da clínica e da equipe.

## Visualizar localmente
Abra `index.html` em um navegador. Para uma experiência de desenvolvimento melhor, use a extensão Live Server do Visual Studio Code.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub, por exemplo `florescer-fisioterapia`.
2. Envie todos os arquivos desta pasta para a raiz do repositório (não envie apenas o ZIP).
3. No repositório, acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde o GitHub publicar o endereço indicado na própria tela do Pages.

## Observações
- O projeto não usa frameworks nem exige instalação de dependências.
- O conteúdo de serviços é genérico e deve ser revisado pela clínica antes de ir ao ar.
- As imagens ilustrativas geradas por IA não substituem fotos reais do estabelecimento.
